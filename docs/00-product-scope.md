# 产品范围与验收

## 产品目标

在固定横屏的第三方 Android WebView 89 中运行通用 KRKR2 游戏。用户从管理员配置
的游戏库中选择游戏，先下载完整资源。只要已联网打开的页面仍保留在 WebView 中，
之后断网仍可启动已安装游戏、继续游玩和读取本地存档。

首个完整验收游戏为《千恋万花》。参考资源只用于开发和验证，不属于模拟器产品
本身。

## 已知目标环境

| 项目 | 当前约束 |
| --- | --- |
| 容器 | 第三方 Android WebView，不可修改 APK |
| 浏览器内核 | Chromium 89，永久不可升级 |
| 设备 | 联发科 Helio G88、4 GB 内存、可用存储大于 60 GB |
| 网络 | 强制 HTTPS；测试时使用热点、DNS 劫持和证书 |
| 屏幕 | 固定横屏 |
| 文件能力 | 不能下载系统文件，不能选择本地文件上传 |
| 游戏来源 | 只显示服务端预先配置的游戏 |
| 离线 | 页面不退出且 URL 不变化时，断网后仍可启动已安装游戏并继续游玩 |
| 存档 | 只保存在本机 |

## 首版范围

- 游戏库列表、游戏详情、容量提示和兼容状态。
- 完整游戏下载、暂停、继续、失败重试、校验和删除。
- 多游戏安装管理和空间占用显示。
- KRKR2/KAG 基础运行、图像、文本、语音、BGM、选择支和本地存档。
- 横屏触摸操作；检测到鼠标、键盘或手柄时启用对应输入。
- 同一页面内的断网游戏启动、断网游玩和本地存档。
- 管理员在服务端配置游戏；用户不能添加任意 URL。
- 游戏兼容等级：已验证、可能可用、不兼容。

## 不在首版但必须保留的范围

- 视频播放。首版允许跳过视频，但产品正式完成前必须支持。详见
  [游戏兼容与视频路线](06-game-compatibility-media.md)。
- 更多游戏专用插件和逐游戏兼容补丁。
- 存档导入、导出、云同步和账号系统。

## 通用模拟器的含义

“通用”表示模拟器提供标准 KRKR2/KAG 能力，并持续内置常见插件；不表示所有带
私有 Windows DLL 的游戏无需适配即可运行。每个游戏需要经过自动扫描和实机验证，
特殊插件可以通过引擎内置实现或逐游戏补丁支持。

## 《千恋万花》验收范围

- 完整下载 `data.xp3`、`video.xp3`、`adult.xp3`，合计
  `4,044,268,983` 字节。
- 联网打开模拟器并完成准备后，保持 WebView 页面不退出；断网后可以启动游戏。
- 能进入标题和开始剧情。
- 文本、背景、立绘、立绘动画、语音、BGM 和选择支正常。
- 存档后重启 App，能够读取并继续。
- 典型剧情场景达到 20 FPS 以上；短时场景切换不以 20 FPS 作为硬指标。
- 连续游玩 60 分钟不崩溃、不被系统因内存压力杀死，内存不持续无界增长。
- 首版可跳过视频；视频里程碑完成后，片头和剧情视频必须正常播放。
