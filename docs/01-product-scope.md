# 产品范围与当前状态

## 产品目标

在固定横屏的第三方 Android WebView 89 中运行通用 KRKR2 游戏。用户从管理员配置的
游戏库中选择游戏，先完整下载资源到浏览器站点存储；只要已联网打开的页面仍保留在
WebView 中，之后断网仍可启动已安装游戏、继续游玩和读取本地存档。存档只保存在
本机，不上传。

首个完整验收游戏为《千恋万花》。参考资源只用于开发和验证，不属于模拟器产品。

## 目标环境（已实机确认）

| 项目 | 约束 |
| --- | --- |
| 容器 | 第三方 Android WebView，不可修改 APK |
| 浏览器内核 | Chromium 89（腾讯 TBS 宿主），永久不可升级 |
| 设备 | 联发科 Helio G88、8 核、4 GB 内存、Mali-G52 MC2 |
| 网络 | 强制 HTTPS；测试用热点 + DNS 劫持 + 证书 |
| 屏幕 | 固定横屏 |
| 文件能力 | 不能下载系统文件，不能选择本地文件上传 |
| 游戏来源 | 只显示服务端预先配置的游戏 |
| 离线 | 页面不退出且 URL 不变时，断网后仍可启动已安装游戏并继续游玩 |
| 存档 | 只保存在本机 |

## 当前能力（已交付并验证）

- 游戏库、下载管理、存档管理、设置四个页面，触屏横屏操作，窄视口自适应。
- 4 GiB 级完整下载：4 MiB 分块、逐块 SHA-256、断点续传、页面刷新自动续传、
  网络错误指数退避、坏块单独修复、全量复核后原子完成、分批删除回收空间。
- 同页断网启动与游玩：启动阶段零网络请求、URL 不变；联网打开页面时预载引擎。
- KRKR2/KAG 运行：文本、背景、立绘、motionplayer 动画、语音、BGM、选择支、
  场景回想、CG 鉴赏；标题随机语音经用户手势 AudioContext 桥接恢复。
- 输入：触摸（含双指点按=右键手势）、键盘与标准手柄（桌面验收，目标设备无外设）。
- 本机存档：IDBFS 按 `gameId` 隔离，定时与页面生命周期同步；存档页按类别查看、
  删除、从服务器导入通关存档。
- 崩溃恢复：同页强制重启/强制终止；致命错误后再次启动自动销毁旧实例并重建。
- 视频覆盖桥：WMV 预转码 H.264/AAC MP4 后离线播放，音画同步、可跳过、播放结束
  正确回到脚本；游戏确认对话框以页面对话框真实应答（不再恒答"否"）。
- 诊断：设置页一键上传产品诊断报告（安装状态、引擎运行时、预取指标、最近错误）。
- Dedicated Worker + OffscreenCanvas 引擎变体，能力探测不满足时自动回退主线程
  baseline 变体（目标设备实机运行 baseline 变体）。

## 未完成与范围外

- 《千恋万花》验收收尾：新游戏开场约 25 秒 scenestart 同步加载停顿的构成分析与
  优化；典型剧情 20 FPS 与 60 分钟稳定性的正式实机测量。见
  [验证记录](09-verification-log.md)。
- 实机游戏内退出后不自动回游戏库：本地已修复并验证，实机复验暂缓。见
  [排障手册](06-troubleshooting.md)。
- 存档导入/导出到设备、云同步、账号系统：范围外。
- 断网冷启动（退出 WebView 后断网重进）：目标宿主断网导航必进错误页，范围外。

## 兼容等级

`catalog.json` 的 `compatibility` 字段与界面徽章：

| 值 | 界面徽章 | 含义 |
| --- | --- | --- |
| `verified` | 已验证 | 在目标 WebView 和指定资源版本上通过完整验收 |
| `development` | 适配优化中 | 可正常游玩，性能与稳定性打磨仍在进行 |
| `incompatible` | （未发布） | 已知缺失能力会阻止游玩 |

每个游戏绑定明确资源版本和 `engineProfile`。兼容补丁只能作用于对应游戏或明确的
插件族，避免修复一个游戏时破坏其他游戏。

## 通用模拟器的含义

"通用"表示模拟器提供标准 KRKR2/KAG 能力并持续内置常见插件（NCB 移植路线见
[决策记录 ADR-008](07-architecture-decisions.md)），不表示所有带私有 Windows DLL
的游戏无需适配即可运行。每个游戏需要经过自动扫描和实机验证；特殊插件通过引擎
内置实现或逐游戏补丁支持。引擎层不包含任何游戏名或厂商名特调，逐游戏内容只
存在于 `engine/profiles/` 配置层。

## 《千恋万花》验收标准

- 完整下载 `data.xp3`、`video.xp3`、`adult.xp3`，合计 `4,044,268,983` 字节。
- 联网打开模拟器并完成准备后，保持 WebView 页面不退出；断网后可以启动游戏。
- 标题、剧情推进、选择支、语音/BGM、立绘动画正常；存档后重启 App 可读取继续。
- 场景回想与 CG 鉴赏可用（已达成）。
- 典型剧情场景 20 FPS 以上；连续游玩 60 分钟不崩溃、不被系统因内存压力杀死，
  内存不持续无界增长（待正式实机测量）。
- 片头和剧情视频正常播放（预转码 MP4 路线已实现，待整轮回归确认）。
