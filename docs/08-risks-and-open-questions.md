# 风险、假设与待确认项

## 最高风险

| 风险 | 影响 | 处理方式 |
| --- | --- | --- |
| 第三方 App 不信任用户自签 CA | 无法打开测试站点 | 实测；失败则改用真实受信任证书 |
| WebView 中跨源隔离和 SAB 被禁用（已发生） | 多 Worker 共享内存文件桥不可用 | FV-2 验证单线程 Wasm + Asyncify；同步 XHR 仅作后备 |
| Service Worker 在目标 TBS 宿主注册失败（已确认） | 断网页面导航必定失败 | 单页内预载引擎并切换 Canvas；产品路径禁止断网导航 |
| IndexedDB 数据未来可能被系统回收 | 游戏缓存丢失 | 5 GB 关闭 App/重启保留已通过；产品启动时仍检查完整性与可用空间 |
| WebView 进程内存上限过低 | 游戏被 Android 杀死 | 有界缓存、减少线程、实机内存剖析 |
| 专用 DLL 未实现 | 个别游戏无法启动或功能缺失 | 发布前扫描、兼容等级、逐插件实现 |
| WMV 软件解码过重 | 视频掉帧或 OOM | 服务端预转码并使用硬件解码 |
| Chrome 89 构建链退化 | Wasm 无法加载 | 固定旧浏览器目标和自动特性检查 |

## 当前假设

- 第三方 App 对同一个 HTTPS origin 的 5 GB IndexedDB 数据在退出和设备重启后
  保持不变（2026-08-12 实机人工确认）。
- WebView 页面可访问普通 Worker；Service Worker API 虽存在，但目标 TBS 宿主注册失败。
- 服务端可以返回项目要求的安全响应头，并支持 Range。
- 管理员允许在游戏发布前生成 Manifest、分块哈希和视频转码副本。
- 用户会等待完整资源下载后再首次启动游戏。

## 下一轮需要确认

1. 同页引擎预载后，目标 WebView 断网启动能否保持 URL、画面和声音正常。
2. 第三方 App 的名称与版本，用于固定测试基线。
3. 游戏是否面向中文用户；首版界面是否只做简体中文。
4. 触摸操作是否需要可视虚拟按键，还是以点击、滑动和长按手势为主。

第 1 项是 D4 当前实机门禁。第 2 项用于测试记录；第 3、4 项影响首版
交互设计，但不阻塞底层可行性验证。
