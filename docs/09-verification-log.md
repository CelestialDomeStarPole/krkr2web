## 已确认的目标环境事实（2026-08-12/13 实机）

- 设备：Android 13、Chromium WebView 89.0.4389.72（腾讯 TBS 046295 宿主）、
  8 核、4 GB 内存、Mali-G52 MC2。
- 站点配额约 27.19 GiB；5 GB IndexedDB 数据在关闭第三方 App 与整机重启后均
  保留（人工确认，首份报告 `20260812-145616-0060df64`）。
- 无 `SharedArrayBuffer`、跨源隔离与 Wasm 共享内存（COOP/COEP 响应头正确，
  已排除为原因）→ 多 Worker 共享内存方案排除。
- Service Worker 在 TBS 宿主注册失败；断网后任何 URL 变化都进入宿主网络错误页
  → 同页断网模型（ADR-006）。
- Wasm i64/BigInt 互操作、WebGL 2、Web Audio、H.264 硬解、触摸与手柄 API 可用。

- **2026-08-24/25（提交 8631b17、5e5a4db）读档/启动优化阶段收尾**：以本轮
  起点引擎（补丁截断至 0084，构建 `c6a31e76`）为 before、当前引擎（含
  0085/0086/0087，构建 `f4998953`）为 after，同一新游戏路径 30 轮限速基准
  （rate=1/6）对照：
  - **读档/启动黑屏：达标 1/5**——boot stall 27903→4431 ms（15.9%），来自
    autopath 快照前缀比对（0085，消除 31 次全表重扫）+ XP3 归档 LRU 持有
    （0086，避免 5.7 MB 索引重复解压）。
  - **对话推进侧四项（语音起播 p50/p95、dialogueWindow stall/longTask、
    p95FrameMs）：未达 1/5，判定为平台期**——结构性归因：rate=1 的 p95≈54.5 ms
    是 0082 主循环 20 fps 节拍的刻意产物（对照两臂同有）；rate=6 的 p95 为引擎
    逐帧合成/上载工作被放大（空闲页 rAF 地板 ~6.1 ms 两档相同可证）；stall 主体
    是一次性场景载入（rate6 stallMax 34.6-35.7 s）而非逐击卡顿。TLG 异步档位
    （0087，默认关闭）、预取扩容、图像园扩容三轮试探均 0% 改善已回退，下一旁
    路方案验证前不再重复同类尝试。
  - **真机复核（报告 `20260825-033618-57e9e521`，TB-X802F/X5）**：
    `verifiedBuild=f4998953`；`SNAPSHOT_HIT` 49 次×39854 项≈195 万项字典扫描
    被旁路，MISS/INCR 均为 0；全量重建仅 4 次（归档注册时）；segmentPark 命中
    5 次/1,015,113 字节；`nativeDecodes 44 / mainDecodes 0`（解码持续全部离开
    主线程）。归因与完整数据见
    [迁移开发记录](10-migration-log.md)。
- **2026-08-25（补丁 0088）场景载入大 tick 修复——对话侧平台期首次突破**：
    取证定位 37.7s 大 tick 的 74% 为剧本 `.scn`（PSB 容器，451,769 节点）在
    同一 PSBFile 实例上被 `.root` 属性双重全量物化（13.2s+14.9s @rate6），
    另有 PSBMedia 单槽容器缓存的交替重解析。0088 修复（实例级物化根缓存 +
    物化备忘录 + 六槽 MRU 容器缓存）后同档 30 轮对照（pre=f4998953）：

    未达 1/5，剩余为单次物化本体 + TJS 剧本处理；详见
    [迁移开发记录](10-migration-log.md) 2026-08-25 条目。
