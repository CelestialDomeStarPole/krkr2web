## 已确认的目标环境事实（2026-08-12/13 实机）

- 设备：Android 13、Chromium WebView 89.0.4389.72（腾讯 TBS 046295 宿主）、
  8 核、4 GB 内存、Mali-G52 MC2。
- 站点配额约 27.19 GiB；5 GB IndexedDB 数据在关闭第三方 App 与整机重启后均
  保留（人工确认，首份报告 `20260812-145616-0060df64`）。
- 无 `SharedArrayBuffer`、跨源隔离与 Wasm 共享内存（COOP/COEP 响应头正确，
  已排除为原因）→ 多 Worker 共享内存方案排除。
- Service Worker 在 TBS 宿主注册失败；断网后任何 URL 变化都进入宿主网络错误页
  → 同页断网模型（ADR-006）。
- Wasm i64/BigInt 互操作、WebGL 2、Web Audio、H.264 硬解、触摸与手柄 API 可用。
